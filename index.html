What I work on

Three threads, one system

A robot is only as good as the loop that closes between what it sees, what it decides and what it does. I'm deliberately building depth in all three rather than specialising early.

Perception

Classical CV from first principles — Hough transforms, histogram equalisation, homographies — alongside trained detectors running on constrained edge hardware.

OpenCV · NumPy · YOLOv8

Control

Working through Ogata chapter by chapter in MATLAB — transfer functions, state-space modelling, stability. The maths that keeps a learned policy from tearing a machine apart.

MATLAB · Control System Toolbox

Learning

Networks written from scratch in NumPy before reaching for a framework, then value-based RL on classic control tasks — heading toward manipulation in simulation.

PyTorch · Gymnasium · MuJoCo
